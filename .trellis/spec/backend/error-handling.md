---

## 基础约束

1. **先复现再修复**：处理缺陷时应先确认错误现象和根因，不用掩盖式修复。
2. **零假设**：错误传播方式不清楚时先询问。
3. **复用优先**：未来已有错误类型或响应工具时，必须优先使用。
4. **最小实现**：只增加当前任务必需的错误处理逻辑。
5. **手术式修改**：不得顺手改动无关错误流程或统一格式。

---

## 返回与记录

- 未登录访问受保护 API 必须返回未认证错误。
- 访问其他 workspace 数据必须返回无权限或不存在，不能泄露数据存在性。
- 非法字段、非法餐次、非法反馈值必须由后端校验拒绝。
- 当前无具体 API 错误响应格式可记录；接入真实源码后，应补充错误类型、捕获位置、返回格式、日志规则和实际示例路径。
