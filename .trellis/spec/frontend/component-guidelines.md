## 基础约束

1. **零假设**：组件框架、样式方案、props 约定不清楚时先询问。
2. **复用优先**：未来已有通用组件时，优先复用而不是重写。
3. **最小实现**：只实现当前交互或展示所必需的组件能力。
4. **手术式修改**：不重构无关组件，不顺手改样式体系。
5. **简单命名**：组件名和属性名应直观、容易搜索，并匹配既有风格。

---

## 组件实现

- 组件实现必须优先满足手机浏览器使用体验，再自然兼容电脑宽度。
- Tailwind CSS 是默认样式方案。
- 当前无标准组件结构和 props 类型约定可记录。
- 接入真实源码后，应补充组件组织方式、props 约定、可访问性规则和实际示例路径。
