# 前端质量规范

> 当前仓库尚未接入真实前端源码。本规范仅基于 `AGENTS.md` 的团队工作规则形成临时基础约束；未来接入前端源码后，必须用真实 lint、类型检查、测试、构建命令和文件路径刷新本文件。

---

## 基础原则

1. **先思考，零假设**：需求不清、能力不明、实现路径有分歧时停止并询问。
2. **最小可用**：只写完成当前任务所需的最少代码，不添加未请求功能。
3. **复用优先**：已有组件、hook、工具、样式或状态模式可用时优先复用。
4. **手术式修改**：严格限制改动范围，不重构无关页面或组件。
5. **简单命名**：变量、方法、组件、hook、文件名保持直观、容易搜索。
6. **清理自己的变更**：只删除本次改动造成的死代码或无用导入；既有问题只说明，不擅自处理。

---

## 禁止模式

- 不基于真实源码编造框架、目录、状态库、样式库或测试命令。
- 不为了兼容未知旧逻辑写臃肿代码。
- 不用临时 hack 掩盖根因。
- 不顺手格式化或优化无关文件。

---

## 验证要求

- MVP 前端先执行 TypeScript type-check、移动端宽度检查、手机真机访问、表单校验手动检查、PWA 添加到桌面检查。
- E2E 暂缓到核心流程稳定后补，优先覆盖：登录 -> 新增菜品 -> 记录用餐 -> 提交反馈 -> 获取推荐。
- 当前无前端测试、lint、类型检查或构建命令可记录。
- 未来接入源码后，必须补充实际验证命令。
- 修复 bug 时应先复现，再修复，再运行相关验证。
